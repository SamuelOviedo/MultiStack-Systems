Eres un Senior Software Engineer trabajando en el repositorio de MultiStack Systems.
La app está construida con React + Vite, desplegada en Vercel, con Supabase para auth
y React Router para navegación. El tema visual es oscuro/terminal (dark theme).

Tu tarea es implementar dos páginas legales públicas y actualizar el footer.
Sigue los pasos en orden. Inspecciona el código existente antes de escribir nada.

--------------------------------------------------------------------------------

Revisa y reporta:
- Archivo principal del router (App.jsx o main.jsx): estructura de rutas actual
- Componente Footer existente: estructura y estilos
- Variables CSS o paleta de colores del tema actual (index.css, App.css o similar)
- Rutas públicas existentes que NO requieren autenticación

NO escribas código hasta completar esta auditoría.

--------------------------------------------------------------------------------
PASO 2 — CREAR DOS COMPONENTES DE PÁGINA
--------------------------------------------------------------------------------

Crear: /src/pages/PoliticaDePrivacidad.jsx
Crear: /src/pages/TerminosDelServicio.jsx

Ambas páginas deben:
- Ser rutas públicas (sin auth requerida)
- Coincidir con el dark theme existente de la app
- Layout de columna única, max-width: 800px, centrado
- Incluir botón "volver arriba" (scroll to top)
- HTML semántico (h1, h2, p, ul, table)
- document.title dinámico con useEffect
- Meta description dinámica para SEO
- Si existe react-helmet o react-helmet-async, usarlo en lugar del useEffect manual

Tipografía:
- Fuente monospace o técnica para headings (consistente con el tema)
- Body: line-height: 1.8, font-size mínimo 16px
- Headings con peso visual claro y espaciado generoso

El contenido exacto de cada página está en las secciones CONTENT_PRIVACIDAD
y CONTENT_TERMINOS más abajo en este archivo. Úsalo tal como aparece.

--------------------------------------------------------------------------------
PASO 3 — AGREGAR RUTAS AL ROUTER
--------------------------------------------------------------------------------

En el archivo principal del router, agregar dos rutas públicas:
  /politica-de-privacidad  →  <PoliticaDePrivacidad />
  /terminos-del-servicio   →  <TerminosDelServicio />

Deben estar FUERA de cualquier wrapper de rutas protegidas.

--------------------------------------------------------------------------------
PASO 4 — ACTUALIZAR EL FOOTER
--------------------------------------------------------------------------------

En el componente Footer, agregar una columna o sección "Legal" con dos enlaces:
  - "Política de Privacidad"  →  /politica-de-privacidad
  - "Términos del Servicio"   →  /terminos-del-servicio

Usar <Link> de React Router (no <a href>).
Estilos consistentes con los demás enlaces del footer.

--------------------------------------------------------------------------------
PASO 5 — SEO META TAGS
--------------------------------------------------------------------------------

Para cada página, configurar dinámicamente:
- document.title
- <meta name="description"> en español (~150 caracteres)
- <link rel="canonical"> apuntando a la URL de producción correspondiente

URLs de producción:
- https://multi-stack-systems.vercel.app/politica-de-privacidad
- https://multi-stack-systems.vercel.app/terminos-del-servicio

--------------------------------------------------------------------------------
PASO 6 — VERIFICACIÓN FINAL
--------------------------------------------------------------------------------

Al terminar, reportar:
1. Lista de archivos creados o modificados
2. Rutas exactas agregadas al router
3. Confirmación de que las páginas son accesibles sin autenticación
4. Advertencias o problemas encontrados

NO modificar: lógica de auth, rutas protegidas existentes, configuración de
Supabase, variables de entorno, ni ningún archivo .env
