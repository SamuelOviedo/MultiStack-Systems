## 8. How to read the graph

Open `graph/graph.html` in any browser (no server needed).

- **Node size** ∝ degree (coupling). Big nodes are architectural hubs.
- **Colour** = layer (default), folder, or detected cluster — toggle top-left.
- **Click** a node to pin it: <span>blue</span> = incoming (who imports it), orange = outgoing (what it imports). Use the **Neighbor depth** slider for transitive reach.
- **Dashed edges** = dynamic / lazy imports (`React.lazy`, `import()`).
- **Highlight issues** toggles surface circular, orphan, dead-code and env-access nodes.
- **Search** filters by filename; **Fit** / **Reset** / **Reheat** control the camera & physics.
