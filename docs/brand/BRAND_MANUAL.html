// 01 — estrategia de marca & voz

Quiénes somos.

MultiStack Systems es una empresa de ingeniería de software con sede en Siguatepeque, Comayagua, Honduras (fundada en 2024), que sirve a Honduras y Latinoamérica. Construimos software a medida y la plataforma operativa que lo gestiona.

Misión

Construir la infraestructura de software que el crecimiento de una empresa exige — desarrollo web, soporte, licencias y automatización con IA — con rigor de ingeniería y accesible para empresas de Honduras y Latinoamérica.

Visión

Ser el socio de ingeniería de software de referencia en la región: un equipo multi-stack en el que una empresa confía desde la primera línea de código hasta el mantenimiento a largo plazo.

// 02 — logotipo & favicon

El isotipo apilado y su lockup.

isotipo · stack isométrico
★ marca oficial

Stack isométrico de tres láminas

La marca es un stack 3D isométrico de tres láminas rómbicas superpuestas, apiladas verticalmente — leyendo como un stack de capas tecnológicas, el significado literal del nombre.

  • Tres láminas rómbicas isométricas en perspectiva 3D, superpuestas al descender.
  • Un gradiente cian→azul recorre el stack. La lámina superior es la más brillante (cian luminoso); cada capa inferior baja en luminosidad hacia azul profundo.
  • El apilado vertical da al asset una relación de aspecto vertical (fuente logo-white.png = 727×845).
No es un cubo, carpeta o forma genérica. Es específicamente un stack rómbico isométrico de tres capas con gradiente cian→azul (tope más brillante).

Zona de seguridad & tamaños mínimos

Margen libre x en los 4 lados, donde x = round(mark_height / 3) (≈ una lámina del stack).

  • 16px — favicon / mark en tab · mínimo absoluto
  • 24–28px — mark en navbar (lockup)
  • 120px — lockup horizontal legible · ancho mínimo
✕ Usos incorrectos
  • ✕ Recolorear las láminas o alterar el gradiente cian→azul.
  • ✕ Estirar, comprimir o cambiar la relación de aspecto.
  • ✕ Rotar o inclinar la estructura isométrica.
  • ✕ Añadir sombras, gradientes o biseles extra.
  • ✕ Reducir por debajo de 16px.

// 07 — design-to-code tokens

Dónde vive cada valor en el código.

Los colores son tripletas HSL en CSS custom properties, definidas en src/index.css (:root = claro, .dark = oscuro) y consumidas por Tailwind vía hsl(var(--token)).

/* src/index.css — :root (light / Notion) */
--background: 0 0% 100%;        /* #ffffff */
--foreground: 40 4% 10%;       /* #191919 */
--primary: 200 98% 39%;        /* #0284c7  sky-700 */
--accent: 192 91% 36%;         /* #0891b2  cyan-700 */
--border: 40 8% 91%;           /* #e9e9e7 */

/* .dark (dark / Kiro.dev) */
--background: 222 43% 7%;        /* #080f1e */
--foreground: 216 100% 97%;     /* #f0f6ff */
--primary: 199 89% 48%;        /* #0ea5e9  sky-500 */
--accent: 187 92% 43%;         /* #06b6d4  cyan-500 */
--border: 213 52% 24%;         /* #1e3a5f */

--radius: 0.5rem;
--ease-brand: cubic-bezier(0.2, 0, 0, 1);
--dur-fast: 150ms; --dur-base: 300ms; --dur-slow: 500ms;
// tailwind.config.ts — mapeo
darkMode: ["class"],
theme.extend.fontFamily: {
  sans:    ["Hanken Grotesk", ...],   // font-sans
  display: ["Sora", ...],             // font-display
  mono:    ["JetBrains Mono", ...],   // font-mono
}
theme.extend.colors.primary = "hsl(var(--primary))"

// 09 — iconografía, espaciado & motion

Detalles del sistema.

Iconografía — Lucide
viewBox 24 × 24 · línea (stroke), sin relleno
stroke-width 2 · currentColor · linecap round
render 22px en chip 48px / radio 11px

El stack isométrico es la única forma de marca rellena. Nunca mezclar iconos rellenos con lineales ni usar emoji como UI.

Motion & profundidad
  • easing cubic-bezier(0.2, 0, 0, 1)
  • duraciones 150ms · 300ms · 500ms
  • lib framer-motion + keyframes CSS
  • hover CTA translateY(-2px)
  • hover card translateY(-3px)
  • rejilla rgba(255,255,255,0.045) + máscara radial
  • glows 0.10–0.16 alpha (solo dark)
  • elevación 0 30px 80px −24px rgba(0,0,0,.85)
